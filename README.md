# Zero to Vibe Coder

A 30-day curriculum for learning to build apps with AI. No CS degree required.

## Tech Stack

- **Vite** - Build tool and dev server
- **React** - UI framework
- **Supabase** - Database and edge functions
- **Lucide** - Icons

## Live Demo

https://ybobobepeurfqekbfdzw.supabase.co/functions/v1/site

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The built files will be in the `dist/` directory.
